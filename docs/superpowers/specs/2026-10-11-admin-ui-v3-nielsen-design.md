# admin-ui V3(+닐슨) 적용 — 1단계 설계

- 날짜: 2026-10-11
- 브랜치: `feat/admin-ui-v3-nielsen`
- 디자인 원본: 캔버스 https://claude.ai/artifact/7Hf6x25iguc9CvU54brtPA 의 `V3(+닐슨)` 페이지 (`project/v3/*.dc.html`, 가이드 `project/v3/Nielsen-Guide.dc.html`)
- 선행: `docs/superpowers/specs/2026-10-11-admin-ui-v2-redesign-design.md` (V2 디자인 시스템 구현)

## 1. 목표와 범위

V3 캔버스는 V2 화면에 닐슨 10원칙 휴리스틱 평가 결과를 적용한 디자인이다. 이 문서는 그중 **현재 백엔드 API로 구현할 수 있는 것 전부**를 admin-ui 에 적용하는 1단계를 정의한다. 백엔드 변경이 필요한 항목은 §8 2단계 백로그로 넘기고, 1단계에서는 현재 API 범위에서 정직하게 처리한다.

- 디자인 시스템(색·타이포·컴포넌트 외형)은 V2 구현을 유지한다. 예외: 포커스 링 토큰.
- 캔버스의 닐슨 핀(`.nh`)과 적용 노트(`.nn`)는 설명용이므로 구현하지 않는다.
- 성공 기준:
  1. V3 캔버스의 각 화면과 상태(정상 / 로드 실패 / 빈 상태 / 확인 다이얼로그)가 admin-ui 에 나타난다.
  2. 휴리스틱 평가의 심각도 3 이상 문제 중 프론트엔드로 해결 가능한 것은 모두 해결된다.
  3. 기존 테스트가 통과하고(문구·동작이 바뀐 테스트는 새 기대값으로 수정, 삭제 금지), 바뀐 동작마다 테스트가 있다.

## 2. 공통 패턴 (`ui/`, `lib/`, `styles/`)

| 패턴 | 구현 | 파일 |

## 3. 셸

- 사이드바 체인 카드 4상태: 정상 / 위변조 / 검증 중 / 확인 불가(마지막 확인 시각 + 다시 시도). `catch(() => {})` 제거.
- 감사 체인 메뉴 배지: 숫자 → "위변조 N".
- RP 전환 실패 시 오류 토스트(현재 무시).
- 상단 바: 검색 placeholder "tenant 이름 · slug 검색", 단축키 표기 OS별(`⌘K` / `Ctrl K`), 도움말 메뉴(§2).

## 4. 인증

- 로그인
  - 하드코딩 지표(58 / 2.4M / 100%) 제거 → 콘솔 용도 문구.
  - 오류는 카드 안 인라인 경고 하나만(토스트 제거), 입력 변경 시 해제. 이메일 칸 autoFocus.
  - `loginForm` 이 `{ ok, status }` 를 반환하도록 변경. 네트워크 오류·5xx → "일시 오류 · 다시 시도", 그 외 실패 → 현재 문구 유지. 423/429 문구는 2단계.
- MFA: 실패 시 인라인 경고(`role="alert"`) + 첫 칸 포커스. "← 로그인으로", "기기를 잃어버렸나요? 운영자에게 MFA 초기화를 요청하세요".
- 비밀번호 찾기·가입 요청: 2xx·4xx 는 계정 존재를 드러내지 않는 동일 안내 유지. 네트워크 오류·5xx 만 "보내지 못했습니다 · 다시 시도". 가입 폼: 이메일 형식 인라인 오류, 비밀번호 `maxLength=128` + "12–128자" 도움말.
- 비밀번호 재설정: 모든 상태에 "← 로그인으로". 토큰 관련 400 → "링크가 만료되었거나 이미 사용되었습니다" 카드 + "재설정 링크 다시 받기".

## 5. 플랫폼 화면

- Tenants: `LoadError`, 생성 버튼 처리 중·연타 방지, 가짜 KPI 제거.
- Activity: Live 표시 실패 상태("연결 끊김 · [N]초 전 갱신", 회색/경고색). "보안 실패만" 스위치 제거. `category`·`tenantId` 필터 URL 보존. p95 KPI 숨김(값이 항상 null).
- 감사 체인: 재검증 중 기존 데이터 유지 + 버튼 "검증 중…". "새로 검증"·"전체 즉시 검증" 통합. 위변조 배너에 `/overview` 의 위변조 tenant 전부 + 행별 Incident 생성. 백필은 더보기 메뉴 + L3 + 위변조 시 비활성. 월간 보고서 시작일 ≤ 종료일 인라인 검증. 가짜 진행률 제거.
- License: 영어 잔재 한국어화(`on-prem only`, `hour(s)`, `(none scheduled)`), 원시 `VALID` 헤드라인 제거(배지만), WARNING/GRACE 조치 카드, 오류는 `LoadError`.

## 6. Tenant 탭 · 설정 탭

### Tenant 공통
- 상세 로드 실패 → `LoadError`. 404 일 때만 "찾을 수 없습니다" + "Tenants로 돌아가기".
- `Tabs`: ←/→ 키 이동. 경고 점 → "확인 필요 N" 라벨 + 사유 툴팁.
- 정지 토스트 "revoke됨" → "회수됨".

### Tenant 탭
| 탭 | 변경 |
|---|---|
| 개요 | 퍼널 실패 → `LoadError`(현재 "등록 시도 없음"). 체인 카드 확인 불가 + 다시 시도. 수동 검증 처리 중·연타 방지 |
| WebAuthn | 변경 비교·SaveBar 유지. "자세히" 문서 링크, `LoadError` |
| AAGUID | 경고 제목 "MDS 미확인 AAGUID [N]건 — 인증기 모델을 확인하세요". 빈 허용 목록 경고 강조. 저장은 L2, 허용 목록이 비면 L3 체크. MDS 엄격 모드 켤 때 L2 |
| API 키 | 빈 상태: 첫 키 발급 + 연동 가이드 링크. 발급 실패 시 폼 값 유지(성공 시에만 초기화). 만료 배지 라벨. 회수 L2 |
| Credentials | `LoadError`. 회수 확인 버튼 처리 중·연타 방지(L3 유지). 검색 placeholder 실제 기능에 맞춤. 필터 범위 표시 "이 페이지 [N]건 중 [M]건", CSV 버튼 "현재 페이지" 명시 |
| 감사 로그 | `LoadError`. 이벤트 타입 칩 → 그룹(인증 · 등록 · 설정 변경 · 키 관리, 프론트 매핑, 현재 페이지 필터 + 범위 표시). 체인 검증 가짜 진행률 제거 |
| 퍼널 | `LoadError` + 다시 시도 |

| 탭 | 변경 |

## 8. 2단계 백로그 (백엔드 동반)

| 항목 | 필요한 백엔드 변경 | 1단계 처리 |
|---|---|---|
| 로그인 잠김 구분 | 잠김 시 423/429 + 남은 시간(`lockedUntil`) | 상태 코드만 전달, 5xx·네트워크만 구분 |
| 재설정 토큰 사전 확인 | `GET /admin/api/password-reset/validate?token=` | 제출 후 400 이면 만료 카드 |
| 복구 코드 재발급·남은 개수 | 재발급 엔드포인트(재인증), `/me` 에 남은 개수 | 보관 안내만 |
| Credential 서버 필터 | `status`/`aaguid`/`transport` 파라미터, 별칭·externalUserId 검색, credential status 필드 | 현재 페이지 필터 + 범위 표시 |
| 감사 로그 서버 필터 | 다중 `action`, 실패만, 그룹, 총 건수 | 현재 페이지 필터 + 범위 표시 |
| 시스템 정보 | hostname · JVM · OS · timezone · 세분화된 uptime | 표시 안 함 |
| 운영자 정지 보호 응답 | `IllegalStateException` → 409/400 + 오류 코드 | 프론트에서 사전 비활성화 |
| 운영자 목록 tenant 이름 | tenant 참조(name/slug) 포함 | 프론트 조인 |
| p95 지표 | Micrometer 계측 | KPI 숨김 |
| 문서·도움말 주소 | 설정값(`/admin/api/profile` 등) | `config/links.ts` 상수, 비면 숨김 |
| 가입 거절 되돌리기 | 거절 취소 API 필요 | 1단계: L1 확인만 |
| 사용자 검증 '요구 안 함' | 백엔드가 boolean 만 저장 — DISCOURAGED 값을 저장·반환하는 필드 필요 | 1단계: 옵션 숨김(필수/권장만) |
| 감사 로그 인증·등록 그룹 | ceremony 이벤트는 별도 테이블 — 감사 로그 API 에 포함 필요 | 1단계: 칩만 제공, 실데이터 매칭은 2단계 |
| 늦은 로그아웃 응답과 재로그인 경합 | 로그아웃 요청에 세션 식별(또는 재로그인 시 이전 로그아웃 무효화) | 1단계: 화면은 즉시 로그인으로, 서버 로그아웃은 뒤에서 전송(재로그인 직후 늦게 처리된 로그아웃이 새 세션을 끊을 수 있음) |

## 9. 진행 방식과 테스트

- 작업 위치: worktree `.claude/worktrees/admin-ui-v3-nielsen`, 브랜치 `feat/admin-ui-v3-nielsen`.
- 묶음 순서와 커밋 단위: (1) 공통 패턴 (2) 셸 (3) 인증 (4) 플랫폼 (5) Tenant 탭 (6) 설정 (7) 다이얼로그·오버레이.

- 마지막: 앱을 실행해 주요 화면·상태를 V3 캔버스와 비교.
